# Muhammad Hafiz - Developer Portfolio

<img src="./public/favicon.svg" width="80" height="80" alt="Portfolio Logo" />

A modern, highly responsive developer portfolio built from scratch to showcase my skills, experience, and projects. The design features a custom "premium fintech glassmorphism" aesthetic with smooth animations and dynamic components.

## ✨ Features

- **Premium Glassmorphism UI:** Custom-built glass frosted-card effects using standard CSS and backdrop filters.
- **Interactive Terminal:** A fully animated, pseudo-terminal "About Me" section powered by Framer Motion.
- **Serverless Contact Form:** Real-time email forwarding directly to my inbox via the Web3Forms API.
- **Interactive Forms:** "Filled Outlined" floating labels for a highly premium form UX.
- **Fully Responsive:** Perfectly adapts from ultrawide 4K monitors down to small mobile screens without any layout breakage.
- **Dark/Light Mode:** Seamless theme toggling to accommodate user preferences.

## 🛠️ Built With

- [React 18](https://react.dev/) - Frontend UI library
- [Vite](https://vitejs.dev/) - Blazing fast build tool
- [Framer Motion](https://www.framer.com/motion/) - Declarative animation library
- [Lucide React](https://lucide.dev/) - Beautiful, consistent icons
- [Web3Forms](https://web3forms.com/) - Serverless contact form API
- Vanilla CSS3 - Custom styling without heavy CSS frameworks

## 🚀 Running Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shenzzuu/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   Create a `.env` file in the root directory and add your Web3Forms Access Key to test the contact form:
   ```env
   VITE_WEB3FORMS_ACCESS_KEY="your-key-here"
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. Open `http://localhost:5173` in your browser.
